Справка по использованию сервиса GOdzilla

Загрузка видео

1. Перейдите по вкладке "Загрузка видео", чтобы загрузить видео с партией игры Го.

2. Выберите требуемый Вами файл из обозревателя файлов.

3. Нажмите кнопку "Продолжить" для того, чтобы перейти к редактированию видео.

Обрезка видео

1. Перетащите левый ползунок (рис. 1) для того, чтобы задать начало видео для дальнейшей обработки.

2. Перетащите правый ползунок (рис. 1) для того, чтобы задать конец видео для дальнейшей обработки.

3. После того, как Вы выбрали нужный промежуток, нажмите кнопку "Продолжить".

Выделение доски

1. Тяните за нижний левый угол красной рамки для того, чтобы изменять размер выделяемой области.

2. Нажмите на красную рамку и потяните до нужной Вам области для её перемещения.

3. После того, как вы выделили игровую доску (пример на рис. 2), нажмите кнопку "Получить SGF".

Получение SGF

1. Для того, чтобы скачать полученный SGF файл, нажмите кнопку "Скачать SGF файл".

2. Файл будет загружен на Ваш компьютер в папку "Загрузки".
