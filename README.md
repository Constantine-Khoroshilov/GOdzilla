# GOdzilla



## Сервер


### Запуск

Установка необходимых пакетов:

```bash
pip install fastapi uvicorn aiofiles python-multipart
```

Запуск сервера:

Для запуска сервера необходимо перейти в директорию `server` и запустить `server.py`:

```bash
cd server
python server.py
```

Адрес сайта:

```
http://localhost:8000
```

При открытии этого сайта в браузере загрузится `index.html`, который (должен быть) расположен в директории `server`. 

**Важно:** чтобы браузер смог подгрузить JS, CSS файлы, а также изображения, ссылки на которые указаны в `index.html`, они должны быть расположены в директории `static`.


### Описание запросов API

Все запросы клиента к серверу должны производится средствами JavaScript, данные отправляются и принимаются в формате JSON (кроме отправки видеофайла, он отправляется путем создания формы). В `static/script.js` уже есть базовый пример с загрузкой видеофайла на сервер.

Чтобы посмотреть и протестировать API без клиента, можно воспользоваться документацией:

```
http://localhost:8000/docs
```

**GET запрос на генерацию ID видеофайла:**

Перед тем, как начать загрузку и обработку видеофайла, необходимо получить его ID для дальнейшей работы с ним.

Пример ID:
`fbd53161-0b8b-4ced-bedc-0f3c26e25cf0`

*URL запроса:*
```
/video_id
```

*Пример ответа сервера в формате JSON:*
```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "not_uploaded" 
}
```

Пример получения ID видеофайла есть в `static/script.js`.

**POST запрос на отправку видеофайла на сервер:**

Перед загрузкой сервер выполнит проверку видеофайла на размер и расширение.
Если размер файла превосходит 30 Гбайт или его расширение отличное от .mp4, .mkv, .mov,
сервер вернет ошибку 400.

Если видеофайл был **полностью** загружен, то сервер на повторный запрос отправки
вернет ошибку 400 с сообщением «The video file has already been uploaded».


*URL запроса:*
```
/upload?video_id=<ID видеофайла>
```

*Пример URL:*
```
/upload?video_id=fbd53161-0b8b-4ced-bedc-0f3c26e25cf0
```

*Тело запроса:*

Форма с полем `file`, содержащее в себе загружаемый видеофайл.

*Пример ответа сервера в формате JSON при успешном выполнении запроса:*
```json
{ 
   "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
   "status": "uploaded" 
}
```

Пример загрузки видеофайла есть в `static/script.js`

**POST запрос на отмену загрузки видеофайла:**

Сервер не удаляет данные видеофайла (ID, область выделенной доски и т.д.), загрузка которого была отменена. Это значит, что загрузку видеофайла после ее отмены можно будет повторить.

*URL запроса:*
```
/cancel_uploading?video_id=<ID видеофайла>
```

*Тело запроса:* отсутствует.

*Пример ответа сервера в формате JSON при успешном выполнении запроса:*
```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "not_uploaded" 
}
```

**POST запрос на отпрвку данных необходимых для обработки**

Данный запрос позволяет отправить данные с временным интервалом (который получается в процессе "обрезки") 
и областью игровой доски (задается **пятью** камнями).

*URL запроса:*
```
/send_processing_data?video_id=<ID видеофайла>
```

*Тело запроса - JSON файл:*
```json
{
  "time_interval": {
    "start": <начальная точка>,
    "stop": <конечная точка>
  },
  "board_area": {
    "stone_radius": <радиус камня в пикселях>,
    "stones": [
      {
        "x": <X координата центра камня>,
        "y": <Y координата центра камня>
      },
      {
        "x": <X координата центра камня>,
        "y": <Y координата центра камня>
      },
      {
        "x": <X координата центра камня>,
        "y": <Y координата центра камня>
      },
      {
        "x": <X координата центра камня>,
        "y": <Y координата центра камня>
      },
      {
        "x": <X координата центра камня>,
        "y": <Y координата центра камня>
      }
    ]
  }
}
```

*Пример ответа сервера в формате JSON при успешном выполнении запроса:*
```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "<статус видеозаписи>" 
}
```

Когда сервер получит **все** необходимые данные (видеофайл, временной интервал и область игровой доски), он **автоматически** начнет обработку видеозаписи. В таком случае, на запрос `/upload` или на запрос `/send_processing_data` сервер ответит статусом `processing`:

```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "processing" 
}
```

**GET запрос на получение статуса обработки**

С помощью данного запроса клиент может отслеживать процесс обработки видеозаписи. Данный запрос необходимо выполнять с некоторой переодичностью после того, как сервер вернул статус `processing`.

*URL запроса:*
```
/get_processing_status?video_id=<ID видеофайла>
```

*Пример ответа сервера в формате JSON:*

* Если видеозапись *в процессе* обработки:
```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "processing",
    "processing": "running"
}
```

* Если видеозапись *обработана*:
```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "processed",
    "processing": "success"
}
```

* Если в процессе обработки *произошла ошибка*:
```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "uploaded",
    "processing": "failure",
    "error": "Error: <описание ошибки>"
}
```

**POST запрос на отмену обработки видеозаписи:**

Данный запрос позволяет принудительно отменить процесс обработки.

*URL запроса:*
```
/cancel_processing?video_id=<ID видеофайла>
```

*Тело запроса:* отсутствует.

*Пример ответа сервера в формате JSON при успешном выполнении запроса:*
```json
{ 
    "video_id": "fbd53161-0b8b-4ced-bedc-0f3c26e25cf0", 
    "status": "uploaded"
}
```

Cтатус `status` будет сброшен с `processing` к `uploaded`

**GET запрос на скачивание SGF файла:**

*URL запроса:*
```
/download_sgf?video_id=<ID видеофайла>
```

Можно указать *дополнительный необязательный* параметр `file_name`, позволяющий
явно задать имя скачиваемого SGF файла:

```
/download_sgf?video_id=<ID видеофайла>&file_name=<имя SGF файла>
```

URL данного запроса необходимо указать в качестве **ссылки** в HTML-коде:
```html
<a href="/download_sgf?video_id=<ID видеофайла>">Скачать</a>
```
